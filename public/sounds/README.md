# Galeria de Áudios Personalizados do Robô ACHAki

Você pode gravar áudios com a sua própria voz (ou efeitos) e salvá-los nesta pasta com os seguintes nomes de arquivo:

- `ml_barrou.mp3` -> Tocado quando o Mercado Livre exige desafio/login
- `shopee_bloqueou.mp3` -> Tocado quando a Shopee pede verificação/captcha
- `amazon_trancou.mp3` -> Tocado quando a Amazon bloqueia o acesso
- `facebook_alerta.mp3` -> Tocado quando o Facebook pede verificação
- `aliexpress_alerta.mp3` -> Tocado para alertas do AliExpress
- `valeu_chefe.mp3` -> Tocado quando o desafio é resolvido com sucesso!

> **Nota:** Se você não colocar nenhum arquivo MP3 aqui, o robô usa automaticamente a **Voz Sintetizada em Português** do navegador com fala personalizada!
